# 🌱 GreenByte AI — Digital Carbon & Energy Intelligence Platform

**GreenByte AI** is a full-stack digital sustainability platform designed to monitor, analyze, and minimize real-time software carbon footprints, memory load, and device power draw. Built for the **IEM Sustainability Hackathon**, it translates abstract energy metrics into actionable real-world impact data, interactive subsystem optimizations, and competitive eco-engagement features.

---

## 🚀 Key Features

* **⚡ Infrastructure Subsystem Carbon DNA:** Dynamic real-time telemetry tracking power draw (Watts), memory allocation, and carbon intensity across CPU, GPU, RAM, Network, and Disk.
* **🔧 Multi-Granularity Eco-Optimizer:**
  * **Individual Subsystem Tuning:** Optimize specific components (e.g., Memory cache flush or GPU frame throttling) independently.
  * **Master Eco-Sweep:** Instantly throttle system draw and flush background allocations across all 5 subsystems simultaneously.
* **🚨 Carbon Anomaly Spike Detection:** Live threshold monitoring that triggers automated visual alerts when system power draw exceeds critical levels.
* **🌐 AI Webpage Carbon Scanner:** Audit asset weight, payload size, load times, and estimated g CO₂ per visit for any live website.
* **⚔️ Live Multi-Player Eco Battle Mode:** Compete head-to-head against other registered leaderboard users to maintain the lowest emission rate (g CO₂/hr).
* **📱 QR Eco Passport & Achievement Badges:** Generates a scannable mobile QR passport displaying unlocked badges (*Eco Novice*, *Optimizer*, *Carbon Warrior*, *Battle Winner*).
* **🤖 Conversational Eco Assistant:** Integrated real-time chatbot for instant queries on platform usage, developer info, and green computing tips.
* **🔋 Hardware & Mobile Battery Sync:** Synchronizes with browser hardware battery status or provides an estimated mobile fallback mode.
* **🌳 Real-World Impact Translator:** Translates carbon savings into tree-day absorption equivalents, car travel distance avoided, and LED bulb hours.

---

## 🛠️ Tech Stack

* **Backend:** Python 3, Flask, Flask-CORS, ElementTree (Live RSS Feed Processing)
* **Frontend:** HTML5, Modern Dynamic JavaScript (ES6+), Tailwind CSS (Glassmorphism UI)
* **Visualizations & Tools:** Chart.js (Real-Time Power Line Charts), QRCode.js (Scannable Badges)

💻 Local Setup & Installation

1. Clone the Repository
Bash
git clone https://github.com/soumya23k/greenbyte-ai.git
cd greenbyte-ai

2. Install Dependencies
Make sure Python 3.8+ is installed, then run:

Bash
pip install flask flask-cors

3. Run the Backend Server
Bash
python app.py

4. Access the Dashboard
Open your browser and navigate to:

Plaintext: 
http://localhost:5000
